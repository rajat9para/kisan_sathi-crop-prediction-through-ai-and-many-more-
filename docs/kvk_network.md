## Overview

Kisan Sathi integrates directly with India's agricultural extension infrastructure. When the autonomous edge node detects an anomalous disease outbreak, severe moisture deficit, or extreme environmental shock, it formats localized advisory reports and coordinates directly with authorized **ICAR Krishi Vigyan Kendra (KVK)** district nodal officers.

## Edge Dissemination Protocol

When anomalous conditions trigger an alert on the edge node:

1. **Structured Alert Generation**: The edge node formats a bilingual micro-alert (English + Hindi/Regional language) containing the localized disease diagnosis, chemical/organic treatment, and urgency rating.
2. **Offline Fallback Dispatch**:
   - If cellular connectivity is available: The node dispatches an SMS via the SIM800L module directly to the registered KVK extension scientist and the farmer's handset.
   - If cellular coverage is absent: The node broadcasts an encrypted packet via the LoRa SX1278 transceiver to the nearest village gateway or neighboring cluster node.
3. **Automated WhatsApp Advisory Formatting**: When connected to the cloud dashboard, farmers can dispatch a pre-populated, formatted diagnostic report to their district KVK officer with a single tap.
